# 🌀 My Physics Engine

> A satisfying, interactive physics simulation featuring springs, gravitation, push/pull forces, and drag — all affecting circles in real time.

*Built with the help of [Raylib Quickstart](https://github.com/raylib-extras/raylib-quickstart).*

---

## Overview

This physics engine is designed around one goal: **making physics feel satisfying**. Watch circles interact through spring connections, gravitational forces, area effectors, and fluid drag. Every parameter is tunable through an in-engine UI so you can craft exactly the simulation you want.

---

## Features

- 🔵 Spawn and interact with physics circles
- 🔗 Connect circles with dynamic springs
- 🌍 Adjustable gravity and drag
- 📡 Area effectors for push/pull zones
- ⚙️ Real-time UI controls for all physics parameters
- 🖥️ Toggleable GUI panel

---

## Controls

### Mouse & Keyboard

| Input | Action |
|-------|--------|
| `LMB` | Spawn circles / interact with UI |
| `RMB` (hold) | Connect a spring line between two circles |
| `RMB` + `Left Shift` (hold) | Drag a circle on a spring, following the mouse |
| `LMB` + `Left Ctrl` (hold) | Spawn multiple circles continuously |
| `LMB` + `Right Shift` | Activate effectors |
| `Tab` | Toggle the right-side GUI panel |
